# Changelog — v1.0.0 (2026-10-17)

## Changes — 2026-10-21
- Added `vps.py`, a one-shot `ssh hostingervps` wrapper for the local container: `uv run vps.py --upload LOCAL REMOTE_DIR` and `uv run vps.py --download REMOTE LOCAL_DIR`, where the flag order is the only difference between the two directions. The local side is relative to the cwd; the remote side resolves against the VPS account home, read once over ssh with `echo $HOME`, so a quoted `~/scraper/...` can never expand to the local home. A path ending in `/` (or an existing directory) transfers every file inside it and skips sub-directories, transfers stream through `cat` in binary so a 300 KB random-byte file round-trips byte-identical, and a failed download removes its own empty destination file. It reuses the hardcoded `~/.ssh/mylinux` key pinned with `IdentitiesOnly=yes` from `vps-pull.sh`, deletes nothing on either box, and is deliberately simple - no resume, retry waits or sha256 pass, which `vps-pull.sh` still covers for the large Parquet collection.
- Added two operator shell scripts for moving the VPS Parquet to Hugging Face, written in `gitinit.sh` style (`set -euo pipefail`, inline `DEFAULT_*` constants at the top, `[OK]`/`[INFO]`/`[ERROR]` prefixes, loud failure instead of retry logic). `hf-upload.sh` pushes Parquet to a Hub dataset with the `HG_TOKEN` access token (the token named `hg_full`, read from the environment or the repo-root `.env`, never passed as `--token` so it stays out of `ps`): with no argument it uploads the hardcoded `pdfs/parquet/books.parquet` on the VPS, with a cwd-relative path or folder it uploads that instead, and the repo is created on first run as `htetmyetflam3/<parquet-name>`, private by default. `vps-pull.sh` downloads Parquet from the VPS over plain `ssh` in BatchMode through this box's `hostingervps` alias for HostName, Port and User, with the private key hardcoded as `DEFAULT_KEY="${HOME}/.ssh/mylinux"` (gitinit.sh style) and pinned with `IdentitiesOnly=yes`, so only that key is ever offered to the VPS and never a general key used for other hosts; it lists `--all` remote `*.parquet` while skipping dot-temps, resumes a half-finished download with `tail -c +N`, and renames its `.name.tmp` into place only after the local sha256 equals the VPS sha256. Neither script deletes anything on either box; the only file `vps-pull.sh` removes is its own unverified dot-temp.
- `hf-upload.sh` authenticates with the token rather than the `ssh/hf` key: the Hub requires a token to create a private repo and to store Parquet through LFS, so an SSH key alone is not enough on this path. Large Parquet needs no local `git-lfs` - `hf upload` streams it and a rerun resumes an interrupted upload.
- Added `huggingface_hub>=1.0` to `pyproject.toml` so `uv sync` provides the `hf` CLI that `hf-upload.sh` calls; the script falls back to `huggingface-cli` and then to `uv run hf`.
