# Changelog — v1.0.0 (2026-10-17)

## Changes — 2026-10-20
- Removed scattered and outdated documentation files across the branch (`README.md`, `INSTALL.md`, `deploy/README.md`, `Engine/MonoSyllabism/map/PENDING-map-changes.md`, `wasm/box/PLAN.md`, `wasm/box/README.md`, `wasm/box/REVERSE-ENGINEERING.md`, and `crawler/scribdl/README.md`).
- Consolidated all parser, classifier (`praser/`, `crawler/bin/pdf_classify.py`), MonoSyllabism `Engine/`, `wasm/box/`, linear per-book Parquet/upload pipeline, and `linga-vector-eval-2026-10-14` (`origin/pr/4`) documentation and architecture into `todo.md`.

## Changes — 2026-10-19
- Accelerated SSH uploads in `crawler/bin/save_remote.py`: enabled OpenSSH connection multiplexing (`ControlMaster=auto`, `ControlPersist=600`, `ControlPath=/tmp/scraper-ssh-%C`), streamed and computed remote SHA-256 in a single SSH pass (`tee -- <path> | sha256sum` for new files, `cat >> <path> && sha256sum <path>` for resumed files), cached created remote directories (`ensure_dir`), and cached `scan/uploaded-host.txt` in memory by file mtime/size.

## Changes — 2026-10-18
- Added Node 22+ discovery across `PATH` and standard version-manager directories (`.nvm`, `fnm`, `.volta`, `/usr/local/bin`) in `crawler/bin/text_collect.py` and `deploy/engine_ready.py` so systemd units do not pick `/usr/bin/node` (v18) when Node 22+ is installed; updated `scripts/systemd_launcher.py` to stop existing `scraper*` units before launching a new transient unit and run `deploy/engine_ready.py --fix` as `ExecStartPre`; stripped leading `-` from saved filenames in `crawler/bin/save_local.py`.
- Replaced run-end batch Parquet flushing with linear per-book processing during upload: `save_local.py` classifies and saves books directly to `convertable/`, `scanned/`, or `old/`; `save_remote.push_file()` directly uploads `scanned/` and `old/` books, and for each book in `convertable/` parses the PDF, uploads it to remote storage, segments the text via `segment_bridge.mjs`, appends one new row to `parquet/books.parquet` on the VPS, and deletes the local PDF. `parquet/` stays on the VPS and is never uploaded to shared host storage.
- Fixed `OverflowError: Python int too large to convert to C int` in `praser/pdf_extract.py` (`parse_tounicode_stream`) when a PDF `/ToUnicode` `bfrange` maps a character code to a multi-code-unit UTF-16BE string (such as Burmese ligatures/kinzi) or out-of-range code points; guarded TrueType format-12 `cmap` ranges, protected `choose_decoding`'s page probe in `crawler/bin/pdf_classify.py`, and updated `scripts/systemd_launcher.py` to remove the staged `/run` environment file only in `ExecStopPost` with `EnvironmentFile=-...`.
- Route operational `main.py` invocations on root/systemd hosts into unique, background transient units by default; preserve environment overrides in a root-only `/run` file, send output to journald, and document direct-run/help behavior and journal access.
- Require Node.js 22+ for builds, systemd installation, Engine readiness, and wasm rebuilding. Added a no-install/no-switch preflight and skip Engine npm dependency installation when its build packages are already present.
- Added a `javascript-obfuscator` pass to the wasm payload builder for all four bundled modules before AES-GCM encryption; moved it to runtime build dependencies and rebuilt `box.wasm`. Added an archived regression assertion that checks every packed module has obfuscator-generated identifiers. Wasm round trips and the fake-download pipeline pass. This is source obfuscation, not bytecode compilation or cryptographic secrecy.
- Consolidated the duplicate `scraper/` tree into `crawler/`; moved the unique `dedup_pdfs.py` into `crawler/bin/` before removing `scraper/`.
- Repointed runtime/deployment/bootstrap paths to `crawler/bin/` and `crawler/scribdl/`, and corrected root-relative `praser/` model/map paths.
- Corrected the Engine mapbuilder imports from the nonexistent `./_function.js` to `./function.js`. Verified the Engine build in isolated before/after copies: before, the imports were treated as external; after, that warning disappeared and the build completed.
- Added `/ssh/` to `.gitignore` to preserve the repo-root SSH directory layout used on `main`.
- Updated the wasm payload pack key to `function.js` to match the corrected mapbuilder imports. Verified archived wasm tests (loader, payload, box, Python/wasmtime), `deploy/engine_ready.py`, the live segment bridge, and `main.py --help`.
- Refreshed `test.zip`'s scraper pipeline and wasm tests for the current `crawler/` and `wasm/box/` paths; the fake-download end-to-end test passed all 15 assertions against this checkout. Preserved the archive's unrelated historical `R_Site` utilities unchanged.
